# The Ward — Clinical Simulation

A browser-based clinical decision-making simulator featuring 70+ cases across emergency medicine, surgery, OB/GYN, pediatrics, neurology, psychiatry, and ethics.

## Play

Open `index.html` in any modern browser. No build step. No server required.

For Android / mobile: the page is installable as a PWA (Add to Home Screen).

## Features

- 70 fully-written cases with branching outcomes, vitals, labs, and clinical pearls
- 6 specialties (Internal Medicine, Surgery, Emergency, OB/GYN, Pediatrics, Psychiatry) — each shapes case mix and starting metrics
- Customizable doctor avatar (gender, skin tone, hair, scrub color, accessory)
- Per-patient SVG sprites that change with clinical status
- Live ECG canvas + 5-channel vitals monitor
- Code Blue random events with 30-second timers
- Career progression: XP, ranks (MS-4 → Attending), achievements, persistent save
- Three difficulty modes: Student / Resident / Attending
- Web Audio synthesised SFX (monitor beeps, alarms, success/failure tones)
- Touch-friendly responsive layout for phone and tablet
- Keyboard shortcuts: `1-4` choose action · `E` end shift · `Enter` dismiss · `Esc` close chart
